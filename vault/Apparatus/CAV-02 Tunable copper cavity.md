# CAV-02 Tunable copper cavity

OFHC copper cylinder with one off-axis copper tuning rod on a rotating arm. Rotating the arm from 0° (rod near the wall) to 180° (rod on axis) tunes the TM010-like mode from about 4.95 GHz to 5.90 GHz.

| Parameter | Value |
| --- | --- |
| Bore | Ø50.80 mm |
| Length | 254.0 mm (rev C) |
| Rod | Ø12.70 mm, pivot offset 6.5 mm, arm 6.5 mm |
| Coupling | two weakly coupled antenna ports in the end caps |
| Barrel drawing | [[CAD-CAV02-001 Cavity barrel]] |
| Rod drawing | [[CAD-CAV02-002 Tuning rod]] |
